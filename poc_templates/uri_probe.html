targetapp:// argument-injection probe

Each button navigates to a crafted targetapp:// URL. If the handler's registry command is "C:\...\app.exe" %1 (unquoted %1), the shell splits on spaces and everything after the first token becomes additional command-line arguments to a locally installed program.

    Proof to capture: the target process's full command line (Process Explorer → Properties → Image), plus C:\Users\Public\wh_uri.txt if a launcher flag landed. A screenshot of calc.exe is not proof; the command line is.
